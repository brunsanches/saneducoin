## 💡 Sobre o Projeto e Propósito

O **Saneducoin** nasceu de uma dor real vivenciada na prática aos 16 anos, ao iniciar a jornada de investimentos no mercado de capitais e notar a carência de materiais didáticos, acessíveis e livres de jargões excludentes ("economês") para jovens investidores.

A concepção inicial foi estruturada e acelerada aos 18 anos por meio dos frameworks de execução e protagonismo do curso **Carreira de Excelência**, promovido pelo **Na Prática (Fundação Estudar)** — iniciativa impulsionada pela visão de educação e filantropia do **BTG Pactual** — e sediado na **Saint Paul Escola de Negócios**, reconhecida entre as melhores do mundo.

## ✨ Funcionalidades Principais (Core Features)

A plataforma foi desenhada sob a diretriz **Mobile-First**, permitindo que o usuário construa hábitos financeiros em micro-momentos do dia (no transporte público, no trânsito ou em intervalos de trabalho e estudo):

* 🕹️ **Trilhas Gamificadas:** Jornada estruturada em níveis que conduz o usuário da superação do endividamento até a alocação em investimentos, utilizando pontos de experiência (XP) como reforço positivo.
* 📊 **Raio-X Financeiro (Business Intelligence):** Painel analítico onde o usuário registra despesas mensais para mapear gargalos orçamentários e identificar oportunidades reais de economia.
* 🎯 **Calculadora de Independência Financeira:** Simulador patrimonial que projeta o montante acumulado exato necessário para gerar a renda passiva mensal desejada pelo usuário.
* 🤖 **Copiloto de Inteligência Artificial:** Assistente virtual nativo projetado para desmistificar termos técnicos, guiar a jornada e facilitar o acesso às ferramentas internas da plataforma.
* 🤝 **Desafios Sociais (Accountability):** Módulo comunitário de metas de economia compartilhadas entre amigos, utilizando a responsabilidade compartilhada como motor de retenção e engajamento.

## 🛠️ Arquitetura Tecnológica e Metodologia

O desenvolvimento do MVP adotou o paradigma de **Desenvolvimento Assistido por Inteligência Artificial (AI-Assisted Development)**, combinando Arquitetura da Informação, contextualização profunda (*context-setting*) e *few-shot prompting* para gerar uma base de código modular e escalável:

* **Front-End:** React.js
* **Estilização e Design System:** Tailwind CSS (Arquitetura Responsiva *Mobile-First*)
* **Plataforma & Orquestração via IA:** Lovable & Engenharia de Prompt Avançada
* **Produto & UX/UI:** Ciclos iterativos de validação empírica (*Feedback Loop*) com usuários reais

## 💻 Como Executar o Projeto Localmente

Caso deseje clonar e rodar este repositório em sua máquina local, certifique-se de ter o **Node.js** instalado e execute os comandos abaixo no terminal:

```bash
# 1. Clone este repositório
git clone [https://github.com/SEU-USUARIO/saneducoin.git](https://github.com/SEU-USUARIO/saneducoin.git)

# 2. Acesse a pasta do projeto
cd saneducoin

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
